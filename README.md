# AI Image generator 1.0 yang sudah support NANO banana: https://ai.studio/apps/drive/16YDtDMtEM1pjb4xUL75f_fozGnqhb9dO

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key
3. Run the app:
   `npm run dev`
Fitur dan hal yang perlu di perhatikan :
1. sudah support bahasa indonesia untuk modifikasi bentuk
2. masih tahap pengembangan
3. pastikan foto wajah mu jelas dan tidak buram agar AI bisa bekerja dengan maximal
